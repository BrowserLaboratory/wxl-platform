# Phoenix 寫作模板庫

---

## 1. 章節開場模板

```markdown
## 什麼是〔概念A〕？

〔2–3 行日常生活情境，用讀者的視角切入〕

你可能覺得：「〔讀者的直覺反應〕」

〔直接回應直覺〕 ʅ（´◔౪◔）ʃ

---

根據〔來源，如教育部線上國語辭典〕的說明，「〔概念A〕」的定義是：

> 〔直接引用原文〕

對，我知道有講跟沒講一樣 ʅ（´◔౪◔）ʃ 。

那我們來看看英文的解釋...

〔英文定義〕 → 〔解析關鍵詞〕 → 〔重新詮釋〕

所以，說到底，〔概念A〕就是：**〔一句話結論〕**

這個定義很重要，因為後面很多東西都會用到它！
```

## 2. 章末結語模板

```markdown
〔本章核心重點（用 ❗ 📌 或 💡 標記）〕

1. 〔第一個核心概念的一句話摘要〕
2. 〔第二個核心概念的一句話摘要〕
〔...最多 6 點〕

〔1–2 行結語，說明這個主題的「未完待續」或更大圖景〕

下一章——「〔下章標題〕」——我們要〔一句話預告內容〕。準備好了嗎？(๑•̀ㅂ•́)و✧
```

**選用收尾語：**
- 學術性章節末：`這個故事，還沒有結局。 (ﾉ◕ヮ◕)ﾉ*:･ﾟ✧`
- 一般章節末：`加油 (๑•̀ㅂ•́)و✧`
- 領域特化收尾語：見對應的 `reference/domain-{name}.md`

## 3. 章節學習目標模板

```markdown
💡 📋 學習目標

看完後，希望你將能夠：

1. 〔可驗證的能力描述，從動詞開始：說明、介紹、了解、實作...〕
2. 〔...〕
3. 〔...〕
```

## 4. 警告/重要提醒標記

較新的章節（Chap 2 v2 風格）使用 emoji 前綴而非 callout 語法：

```markdown
⚠️ ⚠️ 〔警告標題〕

〔內容〕

ℹ️ ℹ️ 〔資訊補充標題〕

〔內容〕

💡 💡 〔立刻可以做的事〕

〔內容〕

❗ 📌 〔核心重點標題〕

〔編號摘要〕
```
