# 台灣繁體中文 vs 中國大陸用語對照表

寫作時**嚴格使用台灣用語**（TW 欄），禁止使用中國大陸用語（CN 欄）。

## 慣用句型差異

| TW 慣用 ✅ | CN 對應 ❌ |
|-----------|----------|
| 所以其實... | 因此... |
| 說白了就是... | 简单来说... |
| 而且... | 而且... （相同，但過度使用是 CN 習慣）|
| 對，我知道... | 我知道... |
| 整理一下，其實就... | 总结一下... |
| 你可以想像... | 可以想象... |
| 你可能會想... | 你可能会想... |

## 標點符號規則

- 使用全形標點：「」（引號）、。！？（句尾）、，（逗號）
- **不使用**半形標點代替繁體全形（英文專有名詞例外）
- 英文技術詞彙保留原文，如：CTF、RSA、AES、HTTPS
- 技術詞彙首次出現格式：中文（English Full Name，縮寫）
  - 例：資訊安全管理系統（Information Security Management System，ISMS）
