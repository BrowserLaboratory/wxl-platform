---
name: research
description: Investigate a question against high-trust primary sources and capture the findings as a Markdown file in the repo. Use when the user wants a topic researched, docs or API facts gathered, or reading legwork delegated to a background agent.
---

When the reading is sizeable enough to run alongside other work, hand it to a background `harness-researcher`; for a lookup of a few pages, do it directly.

1. Investigate the question against **primary sources** (official docs, source code, specs, first-party APIs), not a secondary write-up of them. Follow every claim back to the source that owns it.
2. Write the findings yourself to a single Markdown file (the researcher returns evidence; it does not write files). Cite each claim's source; mark which statements are directly observed, which are claims made by a source, and which are inferences (keep the researcher's labels when it did the reading); and record the verification date and unresolved questions. Write the note in the language docs/agents/language.md assigns to research for the user.
3. Save it where the repo already keeps such notes; match the existing convention, and if there is none, put it somewhere sensible and say where.
