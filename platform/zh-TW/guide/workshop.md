# 教師研習：開始、保存與離開

WXL 在瀏覽器內執行題目。攻擊紀錄、筆記、Code 草稿與解題進度保存在目前裝置、目前瀏覽器的本站資料裡；沒有帳號同步，也不會自動交給教師。

## 公用電腦教室

1. 開始前確認這是自己的資料。出現「這些紀錄是你的嗎？」時，只有確定是自己的作答才選「沿用這些紀錄」；前一位使用者的資料請選「刪除並重新開始」。刪除無法復原。
2. 等待選擇時，平台不顯示既有完成數與標記，也不能提交旗標。清除若顯示結果無法確認，依提示關閉其他分頁並重新載入，先不要繼續作答。
3. 離開前，在每道需要保留的題目下載攻擊紀錄；未解出也可以下載。選「完整」可保留最多內容。打開下載檔確認內容，並移到自己的儲存裝置或個人檔案空間。
4. 一次匯出只包含選定的那一筆攻擊紀錄，不是整台瀏覽器的備份。尚未儲存的筆記文字請另外複製保存。
5. 關閉本站所有分頁再交接。下一位使用者應重新開啟網站並選擇清除；同一個未關閉的分頁沒有自動辨認換人的能力。公用電腦下載資料夾裡的個人檔案也請依教室規範移走。

## 學生自己的設備

- 繼續使用相同裝置、相同瀏覽器與網站網址，並保留本站資料。再次詢問時，確認是自己的紀錄後選擇沿用。
- 未解出的最新紀錄在符合接續條件時會接續；再次進入已解出的題目會開啟新的攻擊紀錄，舊紀錄仍保留。題目頁列出這一題的每一筆紀錄，挑任何一筆都可以匯出，不限於目前作答中的那一筆。
- 換瀏覽器、換裝置或清除本站資料，都不等於沿用原本環境。把下載的 JSON 帶到另一台裝置，可以在同一題的頁面匯入它。
- 匯入一律新增一筆紀錄，不覆蓋也不合併既有紀錄，也不改變解題進度與編輯器草稿。匯入的紀錄可以檢視與再次匯出，但新的作答不會接在它後面——要繼續打這一題，開一筆新的紀錄。
- 檔案屬於哪一題就要在哪一題的頁面匯入；題目不符時平台會拒絕並同時指出兩邊的題目，不會代為寫到別題去。
- 匯入時的完整性檢查只說明檔案內容與檔內雜湊一致，不能用來判斷這份檔案由誰產生。

## 交旗與進度怎麼看

| 畫面 | 代表什麼 | 接下來做什麼 |
|---|---|---|
| 正在驗證並儲存 | 正在處理這次提交 | 等待結果，不要重複提交 |
| 旗標正確＋紀錄已儲存 | 這次答案正確，提交紀錄已完成儲存 | 下載需要保留的攻擊紀錄 |
| 旗標正確＋紀錄未完整儲存 | 答案判定正確，但保存未全部成功 | 先保留可下載的內容；重送會算另一次提交 |
| 目前無法驗證旗標 | 這次未取得有效答案判定 | 等執行環境就緒後再試 |
| 無法讀取解題進度 | 平台暫時無法確認既有進度，並非零完成或資料已刪除 | 按「重新讀取」；仍失敗再依儲存提示處理 |

## 平台更新時

研習開始前，先把上一輪重要內容匯出，關閉本站的其他分頁，再重新載入。舊頁面可能無法使用升級後的資料庫；重新載入會取得新版程式。資料庫升級與題目執行環境是兩件事：頁面重載後，題目裡的登入狀態、上傳檔案及尚未保存的操作仍可能需要重做。

若看到儲存警告，先保存能下載的紀錄與尚未儲存的文字，再處理重載。不要為了排錯直接清除本站資料。

## 教師示範順序

先示範公用電腦的沿用／清除，再選題操作，提交一次答案並分辨判定與儲存訊息，最後下載完整攻擊紀錄並打開檔案。需要收作業時，請另外安排檔案繳交管道；WXL 不會自動收件。
